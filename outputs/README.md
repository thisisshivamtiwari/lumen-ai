# Versioned source archive

Only source files, dependency/configuration files, package READMEs, attribution/licences and selected aggregate metrics from the development outputs are published here. Datasets, feature caches, OOF transaction-level predictions, final prediction CSVs, model weights, logs and submission ZIP/PDF files remain local.

The directory names preserve the original workspace layout because research scripts refer to it. Repeated source files are intentional version snapshots. A package README documents that historical version; root `solution/` is the current development tree. Publication does not certify every archived experiment or claim all were submitted.

For a packaged version, enter its code directory and follow its README with absolute dataset paths. For experiment scripts, read their inputs first: some expect caches and OOF files generated by preceding local steps. The repository is not a self-contained copy of the organiser data.

Full submission-ZIP validation requires the original methodology PDF, which is excluded from this source-only archive. No script submits to the portal automatically.
